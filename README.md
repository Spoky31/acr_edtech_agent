# ИИ-агент для создания образовательных программ АЦР (GigaCowork × Cloud.ru)

Интеллектуальный агент и веб-сервис для методистов **Академии цифрового развития (г. Магас)**, автоматизирующий полный цикл проектирования дополнительных профессиональных программ повышения квалификации (**ДПП ПК** и **стажировок** по 273-ФЗ и Приказу Минобрнауки № 499) и дополнительных общеразвивающих программ (**ДООП** по Приказу Минпросвещения № 629).

---

## 1. Архитектура навыков в стиле Сбер GigaCowork

Логика агента спроектирована в виде модульного каталога навыков (`GIGACOWORK_SKILLS_CATALOG` в `agent_skills.py`), что позволяет бесшовно перенести решение на платформу **GigaCowork**:

| ID навыка | Название навыка | Вход | Выход | Human-in-the-Loop |
| :--- | :--- | :--- | :--- | :--- |
| `skill_01_query_and_reference_analyzer` | Анализ запроса методиста и инспекция референсов | Текст запроса, файлы `.docx`/`.pdf`/`.txt` | `UserQuerySpec`, до 5 вопросов методисту, список багов образца | Да (ответы на вопросы) |
| `skill_02_skeleton_builder` | Проектирование каркаса образовательной программы | Уточненный `UserQuerySpec` | Цель, профстандарт Минтруда, карта компетенций (ЗУН), УП и УТП | Да (утверждение каркаса) |
| `skill_03_content_and_materials_generator` | Генерация полного комплекта материалов курса | Утвержденный каркас `ProgramKit` | РПД, тесты с ключами, задания семинаров, слайды, литература 2026 г. | Автопроверка (`ProgramValidator`) |
| `skill_04_targeted_editor` | Точечная доработка отдельной части комплекта | Текущий `ProgramKit` + команда правки | Пересобранная тема/тест с сохранением остального комплекта | Да |
| `skill_05_legacy_modernizer_and_adapter` | Актуализация старой программы и масштабирование | Исходный `ProgramKit` + новый объем/аудитория | Замена устаревших библиотек на стек 2026 г., пересчет на `16–500+ ч.` | Да |

## 2. Структура репозитория

* `program_validator.py` — ядро данных (`ProgramKit`, `UserQuerySpec`) и детерминированный валидатор:
  * многоуровневая проверка сходимости часов (`Тема ↔ Модуль ↔ УП ↔ УТП ↔ РПД ↔ Календарный график`);
  * контроль матрицы компетенций (каждый результат обучения раскрыт минимум в 1 теме и проверяется минимум 2 оценочными средствами);
  * проверка нормативной базы РФ (`273-ФЗ`, Приказ `№ 499`, Приказ `№ 629`) и верифицированного реестра профстандартов Минтруда РФ (`01.001`, `06.001`, `06.015`, `06.022`, `06.026`, `06.033`, `06.035`, `06.042`);
  * блокировка недоступных в РФ зарубежных сервисов (`ChatGPT`, `Midjourney`, `Kahoot`) и устаревших библиотек (`Python 2/3.7`, `DataFrame.append()`, `load_boston`);
  * инспектор референсных `.docx` (`inspect_reference_docx`), автоматически выявляющий арифметическую ошибку в реальном образце стажировки АЦР на 248 ч и защищающий новую программу от ее переноса.
* `program_exporters.py` — генераторы выгрузки комплекта:
  * документ программы в формате **`.docx`** строго по выбранному шаблону АЦР (`ДООП` или `ДПП ПК / Стажировка`) с пустыми полями реквизитов приказа и ФИО преподавателей;
  * презентации лекций в формате **`.pptx`**;
  * тестовые вопросы с ключами и привязкой к РО в форматах для LMS (**`GIFT`**, **`Moodle XML`**, **`CSV`**);
  * полный слепок данных в **`JSON`** и отчет автопроверки в **`Markdown`**.
* `agent_skills.py` — агентный пайплайн навыков и клиент **`CloudRuLLMClient`** к каталогу моделей **Cloud.ru Evolution Foundation Models** (`Qwen/Qwen2.5-72B-Instruct`, `DeepSeek-V3`, `GigaChat-Max`) с калькулятором токенов, стоимости в рублях и экономии времени методиста (`TokenUsageAndROI`).
* `app.py` — веб-интерфейс методиста АЦР и единый REST API-эндпоинт для автоматической проверки жюри.
* `test_program_validator.py`, `test_program_exporters.py`, `test_agent_skills.py`, `test_api_app.py` — полный набор модульных и интеграционных автотестов по всем 5 эталонным запросам АЦР.

## 3. Быстрый запуск (VS Code / Локально / Cloud.ru)

### Установка зависимостей
```bash
pip install python-docx python-pptx
```
*(Все остальные компоненты, включая HTTP-сервер, API, парсер XML/ZIP и валидатор, работают на стандартной библиотеке Python 3.10+).*

### Настройка подключения к Cloud.ru Evolution Foundation Models (опционально)
```bash
export CLOUDRU_BASE_URL="https://foundation-models.api.cloud.ru/v1"
export CLOUDRU_API_KEY="ваш_ключ_cloud_ru"
export CLOUDRU_MODEL="Qwen/Qwen2.5-72B-Instruct"
```
*(Если переменная `CLOUDRU_API_KEY` не задана, агент автоматически работает в автономном гибридном режиме доменного синтезатора АЦР).*

### Запуск автотестов и генерация всех 5 открытых кейсов в папку `generated_output/`
```bash
python test_program_validator.py
python test_program_exporters.py
python test_agent_skills.py
python test_api_app.py
```

### Запуск веб-сервиса и единого API-эндпоинта
```bash
python app.py
```
После запуска откройте в браузере **`http://127.0.0.1:8000`**.

## 4. Единый API-эндпоинт для автоматической проверки жюри

* **URL:** `POST http://127.0.0.1:8000/api/v1/generate`
* **Пример тела запроса (`application/json`):**
```json
{
  "mode": "full",
  "query": "Нужна программа повышения квалификации на 72 часа «Анализ данных на Python» для сотрудников региональных отделений банков...",
  "answers": {},
  "use_sample_248": false,
  "file_prefix": "case3_bank_72h"
}
```
* **Дополнительные эндпоинты:**
  * `POST /api/v1/analyze` — шаг 1–2 (проверка полноты запроса, инспекция референсов, генерация до 5 уточняющих вопросов);
  * `POST /api/v1/skeleton` — шаг 3 (сборка каркаса программы на согласование методисту);
  * `POST /api/v1/edit` — шаг 7 (точечная пересборка отдельной темы или теста без разрушения остального комплекта);
  * `POST /api/v1/adapt` — масштабирование готовой программы под новый объем часов (`16–500+ ч.`) или новую целевую аудиторию;
  * `GET /api/v1/skills` — выгрузка реестра навыков в формате Сбер GigaCowork;
  * `GET /api/v1/download/<filename>` — скачивание сгенерированных файлов (`.docx`, `.pptx`, `.gift.txt`, `.moodle.xml`, `.csv`, `.json`).
